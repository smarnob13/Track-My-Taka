Full-Stack Production Guide

Deploy "Track My Taka" to GitHub & Vercel

✅ Your Frontend & Cloud Backend are already integrated in this code! Right now, it uses Firebase Firestore for instant real-time cloud persistence across devices, and you can deploy this exact repository to GitHub & Vercel in 3 minutes.

Step 1: Push Your Code to GitHub

  1. Save this file as index.html inside a new folder named track-my-taka.
  2. Go to github.com/new and create a repository named track-my-taka.
  3. Run these terminal commands in your project folder:
git init
git add index.html
git commit -m "Initial release of Track My Taka full-stack app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/track-my-taka.git
git push -u origin main

Step 2: Connect Your Cloud Database for Cross-Device Sync

To keep user accounts and Taka data synced across phones and laptops on your own Vercel domain:

  1. Go to console.firebase.google.com and click Create a project.
  2. Enable Firestore Database (Start in production/test mode) and Authentication (Anonymous/Email).
  3. Copy your Web App firebaseConfig object from Project Settings and paste it into the CUSTOM_FIREBASE_CONFIG variable in the script section of index.html.

Step 3: Deploy Live on Vercel

  1. Log into vercel.com with your GitHub account.
  2. Click Add New... → Project and import your track-my-taka repository.
  3. Leave Framework Preset as Other and click Deploy. Your live URL (track-my-taka.vercel.app) will be live globally in ~15 seconds, and every future git push will auto-deploy!
